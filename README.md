# library-management-system
Management System developed using Oracle SQL

## About the Project
This is a beginner-friendly Library Management System developed using Oracle SQL. It helps manage books, library members, and borrowing records.

## Technologies Used
- Oracle SQL
- SQL Queries

## Database Tables
1. BOOKS – Stores book details and available copies.
2. MEMBERS – Stores library member details.
3. BORROW_RECORDS – Stores book borrowing and return details.

## Features
- Create database tables with constraints.
- Insert books, members, and borrowing records.
- Display book and member details.
- Find books that have not been returned.
- Count books by category.
- Find the number of books borrowed by each member.
- Retrieve information using JOIN operations.
- Filter and group data using WHERE, GROUP BY, and HAVING.

## SQL Concepts Used
- CREATE TABLE
- INSERT INTO
- SELECT
- WHERE
- JOIN
- LEFT JOIN
- GROUP BY
- HAVING
- COUNT
- PRIMARY KEY
- FOREIGN KEY
- CHECK Constraint

## Project Files
- `create_tables.sql` – Creates the database tables.
- `insert_data.sql` – Inserts sample data.
- `queries.sql` – Contains SQL queries to retrieve and analyze information.

## Learning Outcome
Through this project, I practised database creation, data insertion, constraints, joins, and data retrieval using Oracle SQL.
